## 0.1.0

* Added `curve` parameter to `PageAnimationTransition` — pass any `Curve` (e.g. `Curves.easeInOut`) to control easing
* Added `duration` parameter to `PageAnimationTransition` — control transition speed without subclassing
* New transition: `FlipTransition` — 3D perspective Y-axis flip
* New transition: `ScaleFadeTransition` — scale and fade combined
* New transition: `SizeAnimationTransition` — expand/collapse using Flutter's `SizeTransition`
* New transition: `PlatformAdaptiveTransition` — right-to-left on iOS/macOS, bottom-to-top fade on other platforms
